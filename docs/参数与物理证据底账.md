### Tier 2: 正向守恒推导（Forward Derived）

以下状态与变量未在论文中直接制表，但由第一性原理守恒定律唯一确定：

1. **缓发中子先驱核浓度平衡值**：
   由稳态微分方程 $dC_i/dt = 0$ 导出：
   $$C_{i,0} = \frac{\beta_i}{\lambda_i \Lambda} P_{Rx,0}$$
   40 状态中第 22–27 项初始值严格与该平衡公式匹配，相对偏差 $< 10^{-12}$。
2. **各换热器两区域节点均温与出口温度**：
   各区段流体均温定义遵循：
   $$T_m = \frac{T_{in} + T_{out}}{2}$$
   两区逆流换热微元储热方程在稳态下退化为两侧换热平衡：
   $$Q = \dot{m} c_p (T_{in} - T_{out}) = hA (T_m - T_{wall})$$
   模型中的 32 个换热器流体及壁温初值均处于该局部代数平衡极小残差邻域（残差 $< 10^{-5}\text{ K/s}$）。
3. **辐射散热平衡壁温**：
   稳态下排热量与斯特藩-玻尔兹曼辐射热流平衡：
   $$Q_{rad} = \varepsilon \sigma A_{rad} (T_{rad}^4 - T_{space}^4)$$
   代入 $A_{rad}=924.3\text{ m}^2, \varepsilon=0.85, T_{space}=250\text{ K}$，反解平衡辐射壁温 $T_{rad} \approx 416.6\text{ K}$。

### Tier 3: 工程经验基线（Engineering Baseline / 未闭合参数）

在科研过程中，必须清晰指出以下参数属于**工程实现基线**，论文未给出全套独立测定或几何输入：

1. **反应堆燃料等效热容 $\kappa$ 与冷却时间常数 $\gamma$**：
   - 模型当前值：$\kappa = 2.246 \times 10^{-5}\text{ K/J}$，$\gamma = 0.2906\text{ s}^{-1}$。
   - 物理含义：$\kappa = 1/C_{fuel}$（有效热容 $C_{fuel} \approx 44.52\text{ kJ/K}$），$\gamma = hA_{core}/C_{fuel}$。
   - 状态：**未闭合**。论文附录仅有堆芯宏观质量公式，未提供分层有效热容及堆内包壳与结构件折算比例。
2. **反应堆冷却剂温度反馈回路 $\alpha_c$**：
   - 模型当前值：$\alpha_c = -1.67 \times 10^{-5}\text{ K}^{-1}$，参考均温 $T_{c,ref} = 1516.1\text{ K}$。
   - 状态：**实现与文字差异**。论文§5.2.1.1 明确写出“仅考虑平均燃料温度反馈（式 5.4）”，但 SLX 源码中并联连接了冷却剂平均温度反馈支路。
3. **换热器对流换热系数 $hA$ 绝对值与内部几何微元**：
   - IHX 每区传热能力：$hA_h \approx 12,984\text{ W/K}$
   - 状态：论文给出了锯齿形通道 Nu 关联式（如式 5.8），但未公开完整单板通道数、水力直径及流道分流数，属于逆向经验基线。
4. **叶轮机械经验特性二维查找表**：
   - `hexe_compressor_lookup.mat`、`turbine_table1.mat`、`turbine_table2.mat`
   - 状态：来自开源 Sandia 或作者自编 1D 气动损失程序导出的插值曲面，非标准无量纲普适通用图。
5. **`radiator_table.mat` 历史工作区污染残留**：
   - 包含变量：`A_rad`, `Cp_rad`, `M_rad`, `epsilon`, `h_h`, `theta`, 以及偶发的 `ans` (double), `out` (Simulink.SimulationOutput)。
   - 状态：文件哈希 `3f6e8a08f6ec9253b84d07f8eff11d2b093f785bafcfde515f2c6af4ec263304` 已被密码学锁定作为不可变基线，严禁在磁盘上直接写回该文件。运行时由 `start.m` 或包装器自动清洗工作区。

## 4. 核心热力学与代数不一致性诊断清单

为了确保科学研究的严谨性，项目记录以下三项已知代数/热力学非闭合项（绝不为论文好看而私自调平）：

```
[核查清单 1] 堆内传热系数内部代数矛盾:
  - 燃料侧释放热量能力: H_fuel = gamma / kappa = 12938.56 W/K
  - 出口液锂吸热能力:   H_coolant = 13296.00 W/K
  - 相对偏差: +2.76% (导出稳态功率出现 ~81 kW 内部不守恒缺口)。

[核查清单 2] 瞬态出口均温定义的实现不等价:
  - 论文定义: T_mean = (T_in + T_out) / 2 -> 微分上要求 T_out' = 2*T_mean' - T_in' (代数约束)
  - 模型实现: 对 T_mean 和 T_out 分别放置独立积分器
  - 动态影响: 在毫秒尺度存在微小动态响应差异，但对长周期稳态（>500s）无本质影响。

[核查清单 3] 辐射散热器两状态假设的数学秩亏:
  - 离线两状态门检验证明: 在单一常数 UA 和流体热容假设下，论文图 5.18(d) 的壁温和出口温度曲线无法被两状态线性时不变微分方程联合拟合 (paper_reproduced = false 明确保留)。
```

## 5. 长期科研维护与使用守则

1. **不可变数据与测试契约**：  
   `data/provenance/` 下的所有清单与哈希文件受自动化测试保护，任何直接手改都会触发 `PublicationError` 或 `RuntimeError`。
2. **新参数探索准则**：  
   任何修改物理参数（如优化 $hA$、调整 $\alpha_f$）的尝试，必须在 `tmp/` 或分支沙箱中进行，运行前记录前置快照，严禁就地污染根目录模型。
3. **引用与成果发表规则**：  
   在毕业论文或学术期刊中引用本模型时，必须如实陈述 Tier 1/2/3 区别，不得宣称“完全复现原论文图 5.18/5.19 动态曲线”，而应客观表述为“建立了与原论文稳态基准高度自洽、误差透明可溯源的系统级闭式布雷顿循环高阶仿真平台”。
